# Wavver

Wavver is a simple audio player for the Game Boy Advance<br>
<img src="docs/screenshot.png" alt="screenshot"><br>
it very simple and ugly but it does its job<br>
simply place your module file (must be named `wave`) on the `audio` and build, wav files can be converted with [this](https://github.com/Fralacticus/gba-wav-to-s3m-converter)<br>
